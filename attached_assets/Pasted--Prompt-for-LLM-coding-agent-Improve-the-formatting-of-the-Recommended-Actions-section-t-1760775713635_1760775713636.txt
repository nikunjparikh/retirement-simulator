```python
def format_indian_currency(amount):
    """Format currency in Indian lakh/crore notation"""
    if amount >= 10000000:  # 1 crore or more
        crores = amount / 10000000
        return f"₹{crores:.2f} Cr"
    elif amount >= 100000:  # 1 lakh or more
        lakhs = amount / 100000
        return f"₹{lakhs:.2f} lakh"
    else:
        return f"₹{amount:,.0f}"
```

Use this function for all large currency amounts. Show ONLY the lakh/crore format, don't show both formats like "₹10,751,953 total / 1.08 Cr" - just show "₹1.08 Cr".
